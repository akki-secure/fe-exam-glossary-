通信理論編(穴埋め)

22 語 fe-siken.com 用語集(シラバスVer9.2)をもとに作成

通信方向・伝送方式

・(　　　　　　　　) →データが一方向にしか流れない通信方式。送信専用・受信専用の役割が固定されている。テレビ放送やラジオ放送。

・(　　　　　　　　) →送信と受信を交互に行う通信方式。同時には送受信できない。トランシーバー(片方が話している間、もう片方は聞くだけ)。

・(　　　　　　　　) →送信と受信を同時に行える通信方式。電話(両方が同時に話せる)。

変調方式

・(　　　　　　　　) →信号の振幅を変化させて情報を乗せる変調方式。AMラジオ放送。

・(　　　　　　　　) →信号の周波数を変化させて情報を乗せる変調方式。FMラジオ放送。

・(　　　　　　　　) →信号の位相を変化させて情報を乗せる変調方式。振幅や周波数は一定に保たれる。

多重化・デジタル化

・(　　　　　　　　) →アナログ信号を標本化(サンプリング)・量子化・符号化して、デジタル信号に変換する方式。電話の音声をデジタル化する際などに使われる。

・(　　　　　　　　) →伝送路の周波数帯域をいくつかに分割し、それぞれ別の信号を同時に送る多重化方式。ケーブルテレビで複数のチャンネルを同時に送る仕組み。

・(　　　　　　　　) →伝送路を使う時間を細かく分割し、順番に複数の信号を送る多重化方式。電話回線で複数の通話を交代で細かく送る仕組み。

誤り検出・訂正

・(　　　　　　　　) →送信データから計算した検査用の値を付加しておき、受信側で同じ計算をして一致するかを確かめることで誤りを検出する方式。

・(　　　　　　　　) →データに誤り訂正用の冗長なビットを付け加えることで、1ビットの誤りなら検出だけでなく訂正もできるようにした符号方式。

・(　　　　　　　　) →データのビット列の中にある「1」の個数が、偶数(または奇数)になるように検査用のビットを1つ付け加えて、誤りを検出するシンプルな方式。1の個数が奇数だと誤りありと判定する「奇数パリティ」など。

・(　　　　　　　　) →データの誤りを検出するだけでなく、自動的に訂正までできる符号方式の総称。誤り訂正符号。ハミング符号もこの一種。

・(　　　　　　　　) →データを一定のまとまりごとに区切って合計値を計算しておき、その値を使って誤りを検出する方式。

同期方式

・(　　　　　　　　) →受信側が、1ビットずつのタイミング(区切り)を送信側と合わせるための同期方式。

・(　　　　　　　　) →1文字(キャラクタ)単位でデータの区切りを認識できるように、同期用の文字を使ってタイミングを合わせる同期方式。

・(　　　　　　　　) →決まったビットパターン(フラグ)を使って、データのまとまりの始まりと終わりを区切る同期方式。HDLCなどの通信手順で使われる。

・(　　　　　　　　) →1文字ごとにスタートビットとストップビットを付けて、送信側と受信側のタイミングをそのつど合わせる同期方式。

・(　　　　　　　　) →調歩同期式の通信で、1文字分のデータの先頭に付けて「これから送信を始める」ことを知らせるビット。

・(　　　　　　　　) →調歩同期式の通信で、1文字分のデータの末尾に付けて「送信が終わった」ことを知らせるビット。

・(　　　　　　　　) →決まった同期用のビットパターン(SYNコード)を送ることで、送信側と受信側のタイミングを合わせる同期方式。

・(　　　　　　　　) →データを「フレーム」というまとまりで送るとき、そのフレームの開始・終了の位置を送信側と受信側で合わせる同期方式。
