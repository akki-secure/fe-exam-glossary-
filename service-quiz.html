サービスマネジメントの基本

・(　　　　　　　　) →ITサービスを、顧客の求める品質で継続的に提供するための管理。

・(　　　　　　　　) →ITサービスマネジメントの、成功事例をまとめたガイドライン。

・(　　　　　　　　) →ITサービスマネジメントの、国際規格。

・(　　　　　　　　) →利用者からの問合せや要望の窓口となる部署。

・(　　　　　　　　) →サービスの内容や品質の水準を、提供者と利用者の間で取り決めた合意。

・(　　　　　　　　) →SLAに基づいて、サービスの品質を維持・改善する活動。

・(　　　　　　　　) →提供するサービスの内容を、利用者が分かるようにまとめた一覧。

・(　　　　　　　　) →提供するサービスの品質の水準。稼働率99.9%以上など。

・(　　　　　　　　) →災害などが起きても、サービスを止めないための取組み。

サービスの運用

・(　　　　　　　　) →サービスの中断や品質の低下など、通常の運用を妨げる出来事。

・(　　　　　　　　) →インシデントから、できるだけ早くサービスを復旧させるための管理。

・(　　　　　　　　) →インシデントの根本の原因を突き止めて、再発を防ぐための管理。

・(　　　　　　　　) →サービスへの変更が、安全に行われるように管理すること。

・(　　　　　　　　) →変更したものを、本番環境へ展開する作業を管理すること。

・(　　　　　　　　) →サービスを構成する機器やソフトウェアの情報を管理すること。

・(　　　　　　　　) →サービスの構成要素と、その関係の情報を蓄積したデータベース。構成管理データベースともいう。

・(　　　　　　　　) →必要な処理能力を予測し、資源を適切に用意すること。

・(　　　　　　　　) →サービスが、必要なときに利用できるように管理すること。

・(　　　　　　　　) →災害や大きな障害の時にも、サービスを継続、または早期復旧できるようにする管理。

・(　　　　　　　　) →サービスに関する、情報セキュリティを管理すること。

・(　　　　　　　　) →利用者からの、情報提供や設定変更などの依頼。

・(　　　　　　　　) →問題が起きた、本当の原因。

・(　　　　　　　　) →一時的に、影響を抑えるための対策。
