符号化・文字コード

・(　　　　　　　　) →データを送る時に、誤り検出・訂正用の冗長なビット(チェックビットなど)を付け加える技術の事。ノイズが多い回線でも、データが正しく届いたか確認・修復できるようになる。

・(　　　　　　　　) →よく出てくるデータには短いビット列を、あまり出てこないデータには長いビット列を割り当てて、全体のデータ量を小さくする圧縮方式。「A」が50%出るなら短い符号、「D」が5%しか出ないなら長い符号、というように出現頻度に応じて符号の長さを変える。

・(　　　　　　　　) →データの中にある無駄(冗長性)を取り除いて、サイズを小さくする技術。圧縮全般を指す言葉で、ハフマン符号もこの一種。

・(　　　　　　　　) →英字・数字・記号など128種類の文字を、7ビットの数値に対応させた、文字コードの基本規格。

・(　　　　　　　　) →UNIX系OSで使われてきた、拡張UNIXコードと呼ばれる文字コード。日本語の漢字なども扱えるよう拡張されている。

・(　　　　　　　　) →日本語の文字(漢字・ひらがな・カタカナなど)を扱うために、日本工業規格で定められた文字コード。

・(　　　　　　　　) →ASCIIコードをベースに、特定のビットパターンを使って日本語の文字も表現できるようにした文字コード。Windowsなどでよく使われてきた。

・(　　　　　　　　) →世界中の文字や記号を、1つの体系でまとめて表現できるようにした文字コードの標準規格。

・(　　　　　　　　) →Unicodeのもとになった、世界中の文字を収録することを目指した符号化文字集合の事。Universal Coded Character Setの略。

論理・計算理論

・(　　　　　　　　) →「AはBである」のような文を、主語・述語・対象の関係として細かく分析できるようにした論理体系。命題論理より詳しく表現できる。

・(　　　　　　　　) →一般的な前提から、必ず正しい結論を導く推論方法。「すべての人は死ぬ。ソクラテスは人である。よってソクラテスは死ぬ」。

・(　　　　　　　　) →個別の事例から、一般的な法則を推測する推論方法。必ず正しいとは限らない。「これまで見たカラスが全部黒かったから、カラスは黒いだろう」。

・(　　　　　　　　) →文法のルールが厳密に決められている、機械が処理しやすいように作られた言語。プログラミング言語などが該当する。

・(　　　　　　　　) →演算子を数の後ろに置く数式の書き方。かっこが要らず、コンピュータが計算しやすい。「3+4」を逆ポーランドでは「3 4 +」と書く。

・(　　　　　　　　) →決まった数の「状態」を持ち、文字を1つ受け取るたびに状態が変化していく、計算のモデル。文字列が特定のパターンに合うかを判定するのに使われる。

・(　　　　　　　　) →入力に応じて内部の状態を変化させながら動作する、計算の仕組み全般を指す言葉。有限オートマトンはその代表例。

・(　　　　　　　　) →アルゴリズムが答えを出すまでに、データ量に応じてどれくらいの時間がかかるかを表す尺度。O(n)やO(n²)のように書く。

AI基礎・知識工学

・(　　　　　　　　) →専門家の知識をルールとして蓄積し、その知識をもとに推論して助言や診断を行う人工知能の仕組み。

・(　　　　　　　　) →システムが使う知識やルールをまとめて整理・保存しておくデータベース。エキスパートシステムの中核となる。

・(　　　　　　　　) →知識ベースに蓄えられたルールをもとに、新しい結論を導き出す(推論する)プログラム部分。

・(　　　　　　　　) →個々の事例やデータから、共通するルールや特徴を見つけて、幅広く使えるようにまとめる事。機械学習では、未知のデータにも対応できる力として重要。

機械学習の種類

・(　　　　　　　　) →コンピュータがデータから自動的にパターンを学び、新しいデータに対する予測や判断ができるようになる技術。

・(　　　　　　　　) →「入力とその正解(ラベル)」がセットになったデータを使って学習する方法。スパムメール判定など。

・(　　　　　　　　) →正解ラベルのないデータから、データ同士の似ている・似ていないといったパターンを見つけ出す学習方法。顧客のグループ分け(クラスタリング)など。

・(　　　　　　　　) →コンピュータ(エージェント)が実際に行動し、その結果得られる報酬をもとに、より良い行動を試行錯誤しながら学んでいく学習方法。ゲームAIなど。

代表的な機械学習アルゴリズム

・(　　　　　　　　) →入力(説明変数)と出力(目的変数)の関係を、直線の式で予測するシンプルな機械学習の手法。

・(　　　　　　　　) →「はい/いいえ」のような2択の結果が起こる確率を予測する統計手法。線形回帰の考え方をもとに、結果を0〜1の確率に変換する。

・(　　　　　　　　) →「もし〜なら」という条件分岐を木の形に並べて、データを分類・予測するモデル。

・(　　　　　　　　) →たくさんの決定木を作って、それぞれの予測結果を多数決でまとめる事で、精度を上げる手法。

・(　　　　　　　　) →データを2つのグループに分ける境界線(または境界面)を、できるだけ余裕を持たせて引く分類手法。SVMと略される。

・(　　　　　　　　) →たくさんある変数の情報を、できるだけ失わずに少ない変数(主成分)にまとめて、データを見やすくする手法。

機械学習の評価・データ分割

・(　　　　　　　　) →モデルにパターンを覚えさせるために使う、訓練用のデータ。

・(　　　　　　　　) →学習の途中で、モデルの設定(パラメータ)がうまくいっているかを確認するために使うデータ。

・(　　　　　　　　) →学習が終わったモデルの、最終的な性能を確かめるために使う、学習には使っていないデータ。

・(　　　　　　　　) →学習に使っていない新しいデータに対しても、どれだけ正しく予測できるかを表す能力。

・(　　　　　　　　) →学習データに合わせすぎてしまい、新しいデータへの予測精度がかえって下がってしまう現象。オーバーフィッティングともいう。

・(　　　　　　　　) →データをいくつかに分割し、順番にテスト用と学習用を入れ替えながら、モデルの性能を何度も確かめる評価方法。

・(　　　　　　　　) →データをあらかじめ「学習用」と「テスト用」の2つに分けておき、1回だけ評価を行うシンプルな検証方法。

・(　　　　　　　　) →分類モデルの性能を、閾値を変えながら視覚的に評価するためのグラフ。曲線が左上に近いほど性能が良い。

ディープラーニングの基礎

・(　　　　　　　　) →人間の脳の仕組みを参考にした「ニューラルネットワーク」を何層も重ねて、複雑なパターンを学習する機械学習の手法。深層学習。

・(　　　　　　　　) →脳の神経細胞(ニューロン)のつながりを模した、機械学習のモデルの仕組み。

・(　　　　　　　　) →入力層・中間層(隠れ層)・出力層のように、ニューロンを何層にも重ねた基本的なニューラルネットワークの構造。

・(　　　　　　　　) →ニューラルネットワークの予測の誤差を、出力側から入力側に向かって逆に伝えながら、各ニューロンのパラメータを調整していく学習方法。誤差逆伝播法ともいう。

・(　　　　　　　　) →ニューラルネットワークの層を深くしすぎると、誤差を逆伝播する際にその影響がどんどん小さくなり、うまく学習が進まなくなる問題。

・(　　　　　　　　) →ニューロンに入ってきた値を、そのまま出さずに変換して次の層へ渡すための関数。シグモイド関数やReLUなどがある。

学習の応用テクニック

・(　　　　　　　　) →本番の目的で学習させる前に、大量のデータで基礎的なパターンをあらかじめ学習させておく事。

・(　　　　　　　　) →事前学習させたモデルを、特定の目的のデータで追加学習させて、その用途に合わせて微調整する事。

・(　　　　　　　　) →あるタスクで学習した知識を、別の似たタスクに応用して活用する学習方法。

ニューラルネットワークの種類・生成AI

・(　　　　　　　　) →画像の特徴(輪郭や模様など)を効率よく捉えるための、畳み込み処理を使ったニューラルネットワーク。CNN。画像認識でよく使われる。

・(　　　　　　　　) →過去の情報を内部に記憶しながら処理する、時系列データ(文章や音声など)に強いニューラルネットワーク。RNN。

・(　　　　　　　　) →学習したデータの特徴をもとに、それらしい新しいデータ(画像や文章など)を作り出すモデル。

・(　　　　　　　　) →「本物そっくりのデータを作る生成器」と「本物か偽物かを見抜く識別器」を競わせながら学習させる、生成モデルの手法。GAN。

・(　　　　　　　　) →大量のデータで事前学習された、様々な用途に応用できる汎用的な大規模モデル。ファウンデーションモデルともいう。

・(　　　　　　　　) →データに徐々にノイズを加えて壊し、そのノイズを取り除く過程を学習することで、新しい画像などを生成するモデル。

・(　　　　　　　　) →「次にどんな単語が来やすいか」といった、言葉のつながりの確率を学習したモデル。

・(　　　　　　　　) →非常に大量のテキストデータと、多くのパラメータを使って学習させた言語モデル。LLM。文章生成や対話に使われる。

生成AIの学習・活用

・(　　　　　　　　) →データの一部を隠すなどして、人がラベルを付けなくても、データ自身から答えを作り出して学習する方法。

・(　　　　　　　　) →AIから望む出力を引き出すために、指示文(プロンプト)の書き方を工夫する技術。

プログラム言語の分類・処理

・(　　　　　　　　) →ソースコードを機械語に変換する途中で使われる、コンピュータの種類に依存しない橋渡し用のプログラム表現。

・(　　　　　　　　) →ソースコードをコンパイルしてできた、コンピュータが直接実行できる形式のプログラム。オブジェクトプログラムともいう。

・(　　　　　　　　) →「何をどの順番で行うか」という手続き(処理の流れ)を記述していく、昔からある伝統的なプログラミング言語の分類。C言語などが該当する。

・(　　　　　　　　) →データとそれを操作する処理をひとまとめにした「オブジェクト」を中心にプログラムを組み立てる言語。Javaなどが該当する。
