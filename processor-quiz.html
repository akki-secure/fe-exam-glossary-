コンピュータ構成要素編(穴埋め)

46 語 fe-siken.com 用語集(シラバスVer9.2)をもとに作成

プロセッサ

・(　　　　　　　　) →プログラムの命令を読み取って実行し、コンピュータ全体を制御する装置。中央処理装置ともいう。

・(　　　　　　　　) →命令を解読して、各装置へ指示を出す装置。

・(　　　　　　　　) →加減算や論理演算などを実際に行う装置。ALUともいう。

・(　　　　　　　　) →CPU内部にある、非常に高速で小容量の記憶場所。

・(　　　　　　　　) →次に実行する命令が入っている場所(アドレス)を記憶するレジスタ。

・(　　　　　　　　) →いま実行しようとしている命令を保持するレジスタ。

・(　　　　　　　　) →CPUが動作するタイミングを決める信号の1秒あたりの回数。単位はHz。3GHzなら1秒間に30億回のクロックがある。

・(　　　　　　　　) →1つのCPUの中に複数の処理装置(コア)を入れた構成。並列処理で速くなる。

・(　　　　　　　　) →画像処理など、大量の計算を並列で処理することが得意なプロセッサ。

・(　　　　　　　　) →マイクロプロセッサ。CPUの機能を1つのチップに集積したもの。

・(　　　　　　　　) →命令を取り出し、解読し、実行するという一連の流れ。

・(　　　　　　　　) →命令の処理をいくつかの段階に分けて、少しずつずらしながら同時に進める方式。

・(　　　　　　　　) →命令の種類が多く、複雑な命令を持つCPUの設計方式。

・(　　　　　　　　) →命令を単純なものに絞り、高速に実行するCPUの設計方式。

・(　　　　　　　　) →1命令の実行にかかる平均クロック数。

・(　　　　　　　　) →1秒間に実行できる命令数を100万単位で表した性能指標。

メモリ

・(　　　　　　　　) →CPUが直接読み書きする、プログラムやデータを一時的に置く装置。メインメモリともいう。

・(　　　　　　　　) →電源を切っても内容が消えない、大容量の記憶装置。HDDやSSD。

・(　　　　　　　　) →読み書きができるが、電源を切ると内容が消えるメモリ。

・(　　　　　　　　) →コンデンサに電気をためて記憶するRAM。定期的な再書込み(リフレッシュ)が必要で、主記憶に使われる。

・(　　　　　　　　) →フリップフロップ回路で記憶するRAM。高速でリフレッシュ不要だが高価で、キャッシュに使われる。

・(　　　　　　　　) →基本的に読出し専用で、電源を切っても内容が消えないメモリ。

・(　　　　　　　　) →電気的に書換えができ、電源を切っても内容が残るメモリ。USBメモリ、SSD。

・(　　　　　　　　) →CPUと主記憶の速度差を埋めるために置く、高速な小容量メモリ。

・(　　　　　　　　) →必要なデータがキャッシュメモリ内に見つかる割合。

・(　　　　　　　　) →キャッシュのヒット率を考慮した、記憶装置の平均的なアクセス時間。キャッシュ10ns・主記憶100ns・ヒット率0.9なら 0.9×10+0.1×100=19ns。

・(　　　　　　　　) →主記憶を複数に分けて、交互に同時アクセスすることで高速化する方式。

・(　　　　　　　　) →補助記憶の一部を主記憶のように使い、実際の主記憶より大きな領域を扱えるようにする仕組み。

・(　　　　　　　　) →仮想記憶で、記憶領域を固定長の「ページ」に分けて管理する方式。

・(　　　　　　　　) →ページの入替えが頻発し、処理がほとんど進まなくなる状態。

入出力装置・インタフェース

・(　　　　　　　　) →コンピュータへデータを入力する装置。キーボード、マウス、スキャナ。

・(　　　　　　　　) →コンピュータの処理結果を出力する装置。ディスプレイ、プリンタ。

・(　　　　　　　　) →パソコンと周辺機器をつなぐ、広く使われている汎用のシリアルインタフェース。

・(　　　　　　　　) →映像と音声を1本のケーブルでデジタル伝送するインタフェース。

・(　　　　　　　　) →近距離で機器同士をワイヤレスで接続する通信規格。

・(　　　　　　　　) →かざすだけで通信する、ごく近距離の無線通信技術。

・(　　　　　　　　) →HDDやSSDをつなぐためのシリアル方式のインタフェース。

・(　　　　　　　　) →CPUを介さず、周辺装置と主記憶の間で直接データを転送する方式。

・(　　　　　　　　) →実行中の処理を一時中断して、別の処理を優先して実行させる仕組み。

・(　　　　　　　　) →コンピュータ内部で、データや信号をやり取りするための共通の伝送路。

・(　　　　　　　　) →データを1ビットずつ、順番に送る方式。

・(　　　　　　　　) →複数ビットを同時に並べて送る方式。

入出力の性能

・(　　　　　　　　) →フラッシュメモリで記憶する補助記憶装置。HDDより高速で衝撃にも強い。SSDともいう。

・(　　　　　　　　) →磁気ディスクを高速回転させ、ヘッドで読み書きする補助記憶装置。HDDともいう。

・(　　　　　　　　) →データの読み書きを指示してから、完了するまでにかかる時間。

・(　　　　　　　　) →1秒間にどれだけのデータを送れるかを表す指標。単位はbps。
