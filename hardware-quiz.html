論理回路

・(　　　　　　　　) →0と1の信号を使って、論理演算を行う電子回路。

・(　　　　　　　　) →入力がすべて1のときだけ、1を出力する回路。論理積回路ともいう。

・(　　　　　　　　) →入力のどれかが1のとき、1を出力する回路。論理和回路ともいう。

・(　　　　　　　　) →入力を反転させて出力する回路。

・(　　　　　　　　) →ANDの結果を反転させて出力する回路。

・(　　　　　　　　) →ORの結果を反転させて出力する回路。

・(　　　　　　　　) →入力が異なるときだけ、1を出力する回路。排他的論理和回路ともいう。

・(　　　　　　　　) →1ビット同士の足し算を行い、和と桁上がりを出力する回路。

・(　　　　　　　　) →下の桁からの桁上がりも含めて、1ビット同士の足し算を行う回路。

・(　　　　　　　　) →1ビットの情報を記憶できる回路。

・(　　　　　　　　) →出力が、現在の入力だけで決まる論理回路。

・(　　　　　　　　) →出力が、現在の入力と過去の状態の両方で決まる論理回路。
