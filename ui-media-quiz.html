ユーザーインタフェース

・(　　　　　　　　) →利用者とコンピュータの間で、情報をやり取りする接点や仕組み。UIともいう。

・(　　　　　　　　) →アイコンやウィンドウをマウスなどで操作する、視覚的なユーザーインタフェース。

・(　　　　　　　　) →キーボードから文字で命令を入力して操作する、ユーザーインタフェース。

・(　　　　　　　　) →製品やサービスを使うときに、利用者が得る体験全体のこと。

・(　　　　　　　　) →使いやすさ。利用者が目的を、効率よく満足に達成できる度合い。

・(　　　　　　　　) →高齢者や障害のある人を含め、誰もが情報や機能を利用できる度合い。

・(　　　　　　　　) →年齢や能力にかかわらず、できるだけ多くの人が使えるように設計する考え方。

・(　　　　　　　　) →ボタンやチェックボックスなど、画面を構成する部品。

・(　　　　　　　　) →操作の選択肢を一覧にして見せる画面部品。

・(　　　　　　　　) →複数の選択肢から、1つだけ選ぶための部品。

・(　　　　　　　　) →複数の選択肢から、いくつでも選べる部品。

・(　　　　　　　　) →クリックすると選択肢が下に表示される部品。

・(　　　　　　　　) →画面の配置や色など、使いやすい画面を設計すること。

・(　　　　　　　　) →画面の大きさに応じて、表示の配置を自動的に調整するWebデザイン。

画面・帳票設計

・(　　　　　　　　) →入力や表示のための画面を設計すること。

・(　　　　　　　　) →請求書や納品書などの書類の様式を設計すること。

・(　　　　　　　　) →入力された値が、正しい形式かどうかを確かめること。

・(　　　　　　　　) →物や人を管理しやすいように、番号や記号(コード)の付け方を決めること。

・(　　　　　　　　) →コードの入力誤りを見つけるために、末尾に付ける検査用の数字。

・(　　　　　　　　) →データに、連続した番号を順番に付けるコード。

・(　　　　　　　　) →桁ごとに意味を持たせたコード。

・(　　　　　　　　) →コードを見ただけで内容を連想できるように、文字を使ったコード。

Webデザイン

・(　　　　　　　　) →Webサイトの見た目や使いやすさを設計すること。

・(　　　　　　　　) →Webページの文字や画像から、ほかのページへ移動できるようにした仕組み。

・(　　　　　　　　) →Webサイトが、利用者の情報をブラウザに一時的に保存する仕組み。

・(　　　　　　　　) →障害の有無や利用環境にかかわらず、Webの情報を利用できること。

・(　　　　　　　　) →検索エンジンで、Webサイトが上位に表示されやすくする工夫。

マルチメディア

・(　　　　　　　　) →文字、音声、画像、動画などを組み合わせて扱う技術。

・(　　　　　　　　) →画像を、画素(ピクセル)の点の集まりで表現する形式。拡大すると粗くなる。

・(　　　　　　　　) →画像を、点や線などの数式で表現する形式。拡大しても粗くならない。

・(　　　　　　　　) →写真などに向く、静止画の圧縮形式。圧縮すると画質が劣化する(非可逆圧縮)。

・(　　　　　　　　) →256色まで扱える、簡単なアニメーションもできる静止画の圧縮形式。

・(　　　　　　　　) →画質を劣化させず(可逆圧縮)に圧縮でき、透明も扱える静止画の形式。

・(　　　　　　　　) →動画や音声のデータを圧縮する規格の総称。

・(　　　　　　　　) →音楽などの音声データを圧縮する形式。

・(　　　　　　　　) →動画や音声などを1つにまとめて格納するファイル形式。

・(　　　　　　　　) →ダウンロードの完了を待たず、受信しながら再生する配信方式。

・(　　　　　　　　) →データの大きさを、小さくすること。

・(　　　　　　　　) →圧縮したものを、元のデータと全く同じに戻せる圧縮方式。

・(　　　　　　　　) →圧縮すると、元のデータには完全に戻せない圧縮方式。

・(　　　　　　　　) →画像を構成する、最小の点。ピクセルともいう。

・(　　　　　　　　) →動画で、1秒あたりに表示する画像(フレーム)の枚数。単位はfps。

・(　　　　　　　　) →光の色を表す赤・緑・青の3色。RGBともいう。

・(　　　　　　　　) →インクなどの色を表すシアン・マゼンタ・イエローの3色。CMYともいう。

情報メディアの応用

・(　　　　　　　　) →コンピュータを使って作った画像や映像。

・(　　　　　　　　) →現実の景色に、コンピュータの情報を重ねて表示する技術。拡張現実ともいう。

・(　　　　　　　　) →コンピュータで作った世界を、現実のように体験させる技術。仮想現実ともいう。

・(　　　　　　　　) →現実の世界と仮想の世界を融合させ、相互に影響し合うようにする技術。複合現実ともいう。

・(　　　　　　　　) →人の動きを取り込んで、コンピュータ上のキャラクタに反映させる技術。
