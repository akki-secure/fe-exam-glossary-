# 基本情報技術者試験 用語集(fe-exam-glossary)

[fe-siken.com](https://www.fe-siken.com/keyword/) の用語集(シラバスVer9.2準拠)をもとに、
基本情報技術者試験の学習用にまとめている単語集です。サイトの説明文をそのまま使うのではなく、
初学者でも直感的に理解できるよう、平易な言葉と具体的な計算例に書き直しています。

## 現在の収録範囲

fe-siken.com の用語集(シラバスVer9.2)の23カテゴリすべてを収録しています(約3,450語)。
[`index.html`](./index.html) から全ページへ移動できます。各編にカード形式・穴埋め形式の2ページがあります。

- 基礎理論: 離散数学(34語)/応用数学(70語)/情報理論(62語)/通信理論(22語)/計測・制御理論(24語)
- アルゴリズムとプログラミング(144語)
- コンピュータシステム: コンピュータ構成要素(190語)/システム構成要素(89語)/ソフトウェア(172語)/ハードウェア(22語)
- 技術要素: ユーザーインタフェース(74語)/情報メディア(58語)/データベース(134語)/ネットワーク(200語)/セキュリティ(402語)
- 開発技術: システム開発技術(338語)/ソフトウェア開発管理技術(90語)
- マネジメント: プロジェクトマネジメント(159語)/サービスマネジメント(173語)/システム監査(65語)
- ストラテジ: システム戦略(94語)/システム企画(45語)/経営戦略マネジメント(115語)/技術戦略マネジメント(40語)/ビジネスインダストリ(175語)/企業活動(243語)/法務(215語)

用語名と分野構成は元サイトに合わせ、説明文・計算例はすべて学習用に独自に書き下ろしています。
基礎理論の4編(離散数学〜通信理論)は手書きHTMLで、それ以降の編は下記のスクリプトで生成しています。
「情報理論」は元サイトより1語少なくなっています。

## ファイル

各編は `<名前>-cards.html`(カード形式:用語・説明・例を読む)と `<名前>-quiz.html`(穴埋め形式:説明から用語を当てる)の2つです。
いずれもブラウザで開けます。各ページ上部のナビゲーションバーから、目次・前後の編へ移動できます。

## ソースと再生成

- `src/scrape.py` : 元サイトから分野構成と用語名だけを取得し、`src/site/structure.json` に保存します(説明文は取得しません)。
- `src/data/desc/*.txt` : 用語ごとの説明文(`用語|説明|例`)。ここを編集します。
- `src/build.py` : 上記から各編のHTMLと `index.html` を生成します。説明が未作成の用語があると `src/missing.txt` に出力して止まります。

```
python3 src/build.py
```
