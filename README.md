# 基本情報技術者試験 用語集(fe-exam-glossary)

[fe-siken.com](https://www.fe-siken.com/keyword/) の用語集(シラバスVer9.2準拠)をもとに、
基本情報技術者試験の学習用にまとめている単語集です。サイトの説明文をそのまま使うのではなく、
初学者でも直感的に理解できるよう、平易な言葉と具体的な計算例に書き直しています。

## 現在の収録範囲

「基礎理論」カテゴリの「離散数学」サブカテゴリ(34語)を第一弾として収録しています。
他のカテゴリ(応用数学、アルゴリズムとプログラミング、ネットワーク、セキュリティ など)は
今後順次追加していく予定です。

## ファイル一覧

| ファイル | 内容 | 使い方 |
|---|---|---|
| [`discrete-math-cards.html`](./discrete-math-cards.html) | カード形式の単語集。用語・説明・計算例を見やすいカードでまとめたもの | 内容をじっくり読んで理解を深めたいときに使う |
| [`discrete-math-list.html`](./discrete-math-list.html) | リスト形式の単語集(解答付き)。「・用語 →説明」の1行形式でテンポよく読める | 通しでさっと読み返す・見直したいときに使う |
| [`discrete-math-quiz.html`](./discrete-math-quiz.html) | 穴埋め問題シート。用語名を空欄にし、説明文から用語を当てる形式 | 覚えたかどうかを自分でテストしたいときに使う |

いずれもHTMLファイルなので、ブラウザでそのまま開いて閲覧できます。

## 用語の分類(離散数学編)

離散数学編は、以下の4グループに分けて整理しています。

1. **数の表現** — 基数、2の補数、固定小数点数、浮動小数点数、BCD など
2. **シフト演算と誤差** — 論理シフト、算術シフト、桁落ち、情報落ち、オーバーフロー など
3. **集合** — ベン図、和集合、積集合、補集合、部分集合
4. **論理演算** — 論理和、論理積、排他的論理和、ド・モルガンの法則 など
