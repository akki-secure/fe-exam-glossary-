# 基本情報技術者試験 用語集(fe-exam-glossary)

[fe-siken.com](https://www.fe-siken.com/keyword/) の用語集(シラバスVer9.2準拠)をもとに、
基本情報技術者試験の学習用にまとめている単語集です。サイトの説明文をそのまま使うのではなく、
初学者でも直感的に理解できるよう、平易な言葉と具体的な計算例に書き直しています。

## 現在の収録範囲

シラバス(Ver9.2)の全分野を収録しています。[`index.html`](./index.html) から全ページへ移動できます。
基礎理論の4編は fe-siken.com をもとに作成し、それ以降の編は同サイトの用語集の構成を参考に、
用語の選定と説明文を独自に書き下ろしたものです(元サイトの用語一覧とは範囲・語数が異なる場合があります)。

- 離散数学(34語)
- 応用数学(70語)
- 情報に関する理論(62語)
- 通信に関する理論(22語)
- アルゴリズムとプログラミング(51語)
- コンピュータ構成要素(46語)/システム構成要素(43語)/ソフトウェア(43語)/ハードウェア(41語)
- ユーザーインタフェース・情報メディア(49語)/データベース(60語)/ネットワーク(61語)/セキュリティ(77語)
- システム開発技術(55語)/ソフトウェア開発管理技術(40語)
- プロジェクトマネジメント(51語)/サービスマネジメント(42語)/システム監査(32語)
- システム戦略(44語)/経営戦略・技術戦略・ビジネスインダストリ(51語)/企業活動と法務(75語)

合計1,049語。

## 用語の分類

### 離散数学編(4グループ)

1. **数の表現** — 基数、2の補数、固定小数点数、浮動小数点数、BCD など
2. **シフト演算と誤差** — 論理シフト、算術シフト、桁落ち、情報落ち、オーバーフロー など
3. **集合** — ベン図、和集合、積集合、補集合、部分集合
4. **論理演算** — 論理和、論理積、排他的論理和、ド・モルガンの法則 など

### 応用数学編(11グループ)

1. **確率の基礎** — 階乗、加法定理、乗法定理、条件付き確率、ベイズの定理 など
2. **確率分布** — ポアソン分布、二項分布、正規分布、指数分布 など
3. **統計の基本(代表値・散布度)** — 中央値、平均値、標準偏差、分散 など
4. **相関・回帰** — 相関係数、回帰分析、主成分分析、擬似相関 など
5. **推測統計** — 推定、仮説検定、有意水準、第1種の誤り・第2種の誤り など
6. **線形代数** — ベクトル、行列、固有値、固有ベクトル、逆行列 など
7. **数列** — 等差数列、等比数列、フィボナッチ数列
8. **微分積分・数値計算** — 三角関数、ニュートン法、微分、積分、丸め誤差 など
9. **グラフ理論** — グラフ理論、有向グラフ、無向グラフ
10. **待ち行列理論** — 待ち行列モデル、サービス時間、平均到着率 など
11. **最適化** — 最適化問題、動的計画法

### 情報理論編(11グループ)

1. **符号化・文字コード** — ハフマン符号、情報源符号化、ASCIIコード、Unicode など
2. **論理・計算理論** — 述語論理、演繹推論、帰納推論、逆ポーランド表記法、時間計算量 など
3. **AI基礎・知識工学** — エキスパートシステム、知識ベース、推論エンジン、汎化
4. **機械学習の種類** — 機械学習、教師あり学習、教師なし学習、強化学習
5. **代表的な機械学習アルゴリズム** — 線形回帰、決定木、ランダムフォレスト、SVM など
6. **機械学習の評価・データ分割** — 学習データ、過学習、交差検証、ROC曲線 など
7. **ディープラーニングの基礎** — ニューラルネットワーク、バックプロパゲーション、活性化関数 など
8. **学習の応用テクニック** — 事前学習、ファインチューニング、転移学習
9. **ニューラルネットワークの種類・生成AI** — CNN、RNN、GAN、拡散モデル、大規模言語モデル など
10. **生成AIの学習・活用** — 自己教師あり学習、プロンプトエンジニアリング
11. **プログラム言語の分類・処理** — 中間言語、目的プログラム、手続型言語、オブジェクト指向言語

### 通信理論編(5グループ)

1. **通信方向・伝送方式** — 単方向、半二重、全二重
2. **変調方式** — AM、FM、PM
3. **多重化・デジタル化** — PCM、FDM、TDM
4. **誤り検出・訂正** — CRC、ハミング符号、パリティチェック、ECC、チェックサム
5. **同期方式** — ビット同期、フラグ同期、調歩同期、SYN同期、フレーム同期 など

## ソースと再生成

基礎理論の4編以降のHTMLは、`src/data/*.txt`(用語データ)から `python3 src/build.py` で生成しています。
用語を追加・修正するときは `.txt` を編集して再実行してください(`index.html` も更新されます)。
