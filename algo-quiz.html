アルゴリズムとプログラミング編(穴埋め)

データ構造

・(　　　　　　　　) →同じ型のデータを連続して並べ、番号(添字)で取り出せるようにしたデータ構造。a[0]、a[1]、a[2]…のように番号で要素を指定する。

・(　　　　　　　　) →データを鎖のようにつなげて並べたデータ構造。各要素が次の要素の位置(ポインタ)を持つ。途中への挿入・削除がポインタのつなぎ替えだけで済む。

・(　　　　　　　　) →最後に入れたデータを最初に取り出す(後入れ先出し、LIFO)データ構造。積み重ねた皿は、最後に置いた皿から取る。

・(　　　　　　　　) →最初に入れたデータを最初に取り出す(先入れ先出し、FIFO)データ構造。レジの行列は、先に並んだ人から順に会計する。

・(　　　　　　　　) →根(ルート)から枝分かれして葉へ向かう階層的なデータ構造。フォルダの階層構造。

・(　　　　　　　　) →各節点の子が最大2つの木構造。左の子と右の子がある。

・(　　　　　　　　) →左の子は親より小さく、右の子は親より大きくなるよう作った二分木。探索が速い。

・(　　　　　　　　) →親が子より常に小さい(または大きい)という決まりを持つ木構造。最大・最小値をすぐ取り出せる。

・(　　　　　　　　) →データが記憶されている場所(アドレス)を指し示す値。

アルゴリズム

・(　　　　　　　　) →問題を解決するための手順や計算方法のこと。

・(　　　　　　　　) →先頭から順番に1つずつ比べて、目的のデータを探す方法。10個なら最悪10回、n個なら最悪n回比べる。

・(　　　　　　　　) →整列済みのデータの真ん中と比べ、探索範囲を半分ずつに絞っていく探索方法。1000個でも約10回で見つかる。

・(　　　　　　　　) →データからハッシュ関数で格納位置を計算し、すばやく格納・探索する方法。

・(　　　　　　　　) →ハッシュ法で、異なるデータが同じ格納位置に計算されてしまうこと。シノニムともいう。

・(　　　　　　　　) →隣り合う要素を比べて入れ替えを繰り返し、大きい値を端へ押し出していく整列法。

・(　　　　　　　　) →未整列部分から最小値を選んで先頭と入れ替えることを繰り返す整列法。

・(　　　　　　　　) →未整列の要素を、整列済み部分の正しい位置に挿入していく整列法。

・(　　　　　　　　) →基準値(ピボット)を決め、それより小さいグループと大きいグループに分けながら整列する高速な整列法。

・(　　　　　　　　) →データを半分ずつに分けて整列し、整列済みの列を併合(マージ)していく整列法。

・(　　　　　　　　) →ヒープを作り、最大(最小)値を順に取り出して整列する方法。

・(　　　　　　　　) →関数が自分自身を呼び出して処理を進める方法。階乗n!を n×(n-1)! として計算する。

・(　　　　　　　　) →アルゴリズムの実行にかかる時間や記憶量を、データ量nの関数として表したもの。O(n)のように書く。

プログラミング

・(　　　　　　　　) →データを一時的に記憶しておく名前付きの入れ物。

・(　　　　　　　　) →プログラムの実行中に値が変わらないデータ。

・(　　　　　　　　) →ひとまとまりの処理に名前を付け、何度でも呼び出せるようにしたもの。

・(　　　　　　　　) →関数を呼び出すときに渡す値。

・(　　　　　　　　) →関数が処理を終えたあと、呼び出し元に返す値。

・(　　　　　　　　) →条件が成り立つかどうかで、実行する処理を切り替える制御構造。if文。

・(　　　　　　　　) →同じ処理を、条件を満たす間、何度も繰り返す制御構造。for文、while文。

・(　　　　　　　　) →上から順に処理を実行する、基本的な制御構造。

・(　　　　　　　　) →順次・選択・繰返しの3つの構造だけでプログラムを組み立てる考え方。

・(　　　　　　　　) →処理の流れを、図形と矢印で表した図。

・(　　　　　　　　) →試験で使われる、プログラム言語に近い形でアルゴリズムを書く表記法。

・(　　　　　　　　) →プログラムを1行ずつ追って、変数の値がどう変わるかを確かめること。

・(　　　　　　　　) →関数へ変数の値のコピーを渡す方法。関数内で変えても元の値は変わらない。

・(　　　　　　　　) →関数へ変数の場所(アドレス)を渡す方法。関数内で変えると元の値も変わる。

プログラム言語

・(　　　　　　　　) →ソースプログラムを、まとめて機械語へ翻訳するソフトウェア。

・(　　　　　　　　) →ソースプログラムを1行ずつ解釈しながら実行するソフトウェア。

・(　　　　　　　　) →アセンブリ言語のプログラムを機械語へ翻訳するソフトウェア。

・(　　　　　　　　) →CPUが直接理解して実行できる、0と1で表された命令。

・(　　　　　　　　) →データと処理をまとめた「オブジェクト」を組み合わせてプログラムを作る考え方。

・(　　　　　　　　) →オブジェクトの設計図。データ(属性)と処理(メソッド)を定義する。

・(　　　　　　　　) →クラスをもとに実際に作られたオブジェクト。

・(　　　　　　　　) →既存のクラスの性質を引き継いで、新しいクラスを作ること。

・(　　　　　　　　) →データと処理をひとまとめにして、内部の詳細を外から隠すこと。

・(　　　　　　　　) →同じ命令を送っても、オブジェクトの種類によって違う動作をする性質。多相性ともいう。

マークアップ言語

・(　　　　　　　　) →Webページの構造を記述するマークアップ言語。

・(　　　　　　　　) →利用者が独自のタグを定義できる、汎用のマークアップ言語。<name>山田</name>のようにデータの意味をタグで表す。

・(　　　　　　　　) →「名前:値」の組でデータを表す軽量なデータ記述形式。Webの通信でよく使われる。

・(　　　　　　　　) →HTMLで作った文書の見た目(色・配置など)を指定する言語。

・(　　　　　　　　) →Webブラウザ上でページに動きをつけるために使われるスクリプト言語。
